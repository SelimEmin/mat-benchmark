# Censoring-aware benchmark and validation diagnostics for human monoamine transporter activity prediction

Code and data for *A NET binding-versus-functional potency offset is a
property of the assay cell, not of the assay format: consequences for external validation
of monoamine transporter models*.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23144306.svg)](https://doi.org/10.5281/zenodo.23144306)
&nbsp;Code: MIT · Data: CC BY-SA 4.0

Archived at Zenodo: [10.5281/zenodo.23144306](https://doi.org/10.5281/zenodo.23144306)

The short version of the finding: the binding-versus-functional potency discrepancy at the
human norepinephrine transporter is +0.507 log units in the seventeen ChEMBL documents that
use [¹²⁵I]RTI-55 as the NET radioligand and +0.038 — indistinguishable from zero — in the
twenty-one that use [³H]nisoxetine. The pooled per-target figure the literature would quote
is an average over assay cells that differ by more than a log unit.


## Layout

```
.                      current-round analysis scripts and their outputs,
                       plus the shared artefacts every script reads
├─ data/               curated inputs: the ChEMBL re-derivation, the external
│                      sets, the within-document pair tables
├─ src/                earlier-round analysis scripts — see src/README.md,
│                      they need a flat working directory
├─ results/            stored outputs of the earlier rounds
├─ figures/            standalone analysis figures
├─ tables/             the argument tables, as CSV and Markdown
├─ figures/numbered/   the numbered figure series of the article
├─ figgen/             the figure pipeline that draws them
└─ repro/              end-to-end verification of the two published externals
```

The repository is the computation, not the write-up: `manuscript.tex`, its bibliography
and the built PDF are not here, because a copy would drift from whatever version is under
review. The numbered figures are, because `figgen/` computes them from the model and the
deposited data in the same way `tables/` is produced.

`mat_profiles.csv` at the root is the benchmark itself: 2,849 compounds, with
censoring-aware pDAT/pNET/pSERT labels, per-target censoring flags, the DAT/SERT log
ratio and the Murcko scaffold. It is the table the models are trained on.

Almost everything else is generated by the scripts here from
`data/chembl_rederivation_activities.csv` and the external-set files in `data/`. Two
things are not script outputs: the 55-compound releaser/blocker reference set in
`substrate_reference_set.csv`, which is assembled by hand from standard
monoamine-transporter pharmacology, and the chemotype stratification figure 11 is drawn
from, whose values are transcribed from the article's Table 9 so that figure and table
cannot disagree.

## 1. Assay-modality labelling of the human MAT corpus

ChEMBL's `assay_type` field is unreliable for this corpus: 8,420 of 8,801 IC₅₀ records are
tagged `B` (binding), which would make functional uptake data 2.4% of the corpus. Reading
the modality from the free-text `assay_description` instead gives a different picture.

`modality_classifier.py` applies ordered, high-precision regular expressions. The phrase
"uptake site" / "reuptake site" is neutralised first, because there the word names the
target rather than the measurement. Descriptions asserting both go to a `conflict` bucket
and undecidable ones to `unclear`; both are excluded from the labelled file.

| | records | share of classifiable |
|---|---|---|
| binding | 8,785 | 61% |
| functional uptake | 5,601 | 39% |
| conflict | 810 | — |
| unclear | 1,554 | — |

**`modality_labels_v2.csv`** — 11,693 (compound, target, modality) rows over 5,796
compounds, each the median pChEMBL of that cell, with the contributing record and document
counts. Columns: `chembl_id, smiles, target, modality, p, n_records, n_docs`.

| target | binding compounds | uptake compounds |
|---|---|---|
| DAT | 1,936 | 1,216 |
| NET | 1,940 | 1,732 |
| SERT | 3,095 | 1,774 |

**`pooled_labels_v2.csv`** — the same compounds with modality pooled, for like-for-like
comparison.

## 2. Mechanism labelling: substrate-type releaser vs uptake blocker

`substrate_smarts.py` assigns mechanism **from structure alone**, never from the Kᵢ/IC₅₀
ratio — that ratio is the outcome in the assay-format analysis, so using it to stratify
would be circular. Blocker-defining motifs are applied first as hard negatives
(α-pyrrolidinophenone, tropane, aryloxy/diaryl ether, piperazine, fused tricyclic,
benzhydryl, α/β-ester, N-tert-alkyl), then a molecular-weight and ring-count gate, then
substrate cores (arylethylamine, cathinone, constrained amine, arylmorpholine,
aminooxazoline, aminoindane).

`validate_substrate.py` scores it against a 55-compound reference set assembled from
standard monoamine-transporter pharmacology:

- recall on releasers **27/28 = 96%** (MDAI missed, on ring count)
- specificity on blockers **27/27 = 100%**
- balanced accuracy **98%**

## 3. Corrected structures and a PubChem cross-check

`struct_corrected.csv` records one correction: Cocaine was held as benzoylecgonine, the
inactive hydrolysis metabolite (C₁₆H₁₉NO₄, MW 289.33) rather than the methyl ester
(C₁₇H₂₁NO₄, MW 303.36). No script reads that file — it is the audit record. The fix is
applied in code, in `external_final.py`, `repro/reproduce.py`, `figgen/prep.py` and
`figgen/fig13.py`, each of which substitutes (−)-cocaine by name. Effect on the reported
metrics is below 0.011 r² at every target. The three modality scripts do not apply it and
do not need to: they select on the InChIKey skeleton block, which is the same for both
structures, and ECFP4 ignores the stereochemistry that distinguishes them.

`structure_qc.csv` is the full cross-check of all 40 structures carrying PubChem CIDs.
After the correction: 12 exact formula matches, 28 free-base-versus-PubChem-salt
differences (correct practice — the models use free bases), **0 genuine mismatches**.

## 4. Revised analyses

`internal_full.py` — 20-seed scaffold CV of the pre-registered model collecting r², RMSE,
out-of-fold predictions and nearest-neighbour similarity in one pass. Reproduces the
manuscript's Table 2: r² 0.584 / 0.502 / 0.538 against published 0.584 / 0.501 / 0.541;
RMSE 0.736 / 0.811 / 0.887 against 0.735 / 0.811 / 0.884.

`external_final.py` — every external-set number the manuscript reports, recomputed under
one convention: structures desalted to the largest fragment, CXSMILES annotation blocks
stripped before parsing, cocaine taken as (−)-cocaine, and training overlap removed on
the InChIKey **skeleton block**. It supersedes `src/competency2.py`, which filtered on the full
InChIKey; the superseded filter is kept as `reachability_fullkey_superseded.{py,json}`
(the script still writes `reachability.json`) so the change can be audited. Writes
`external_final.json` and prints the rows of manuscript Tables 6 and 14.

It also runs the attainability test: for each external cell, where the external set's
response variance and nearest-neighbour similarity fall among the values attainable by
any random internal subset of the same size (20,000 draws per cell). **No matched
comparator exists for any of the 9 cells.** Every cell fails on similarity and four also
on variance, so a rejection sampler with a widening tolerance returns a band matched to
nothing in every case.

**This is a correction.** The superseded script found a matched comparator for 3 of 9
cells, all three from the PDSP/BindingDB set, and the reason is the exclusion rule. ECFP4
is computed without stereochemistry, so 13 of that set's 29 full-key-filtered compounds —
nine recorded without stereodescriptors where training specifies them, two resolved
enantiomers of a racemate held flat in training, and two the sertraline pair — carry
fingerprints identical to compounds the model was fitted on. Their nearest-neighbour
similarity is 1.0 by construction, lifting the set median from 0.41 to 0.63 and into the
attainable range. On those 13 the model's mean absolute error is 0.19–0.42 log units
against 0.72–1.01 on the other 16. Removing them changes the set's reported performance:

| PDSP/BindingDB | full key (n=29) | skeleton block (n=17) |
|---|---|---|
| DAT r² | 0.316 | 0.300 |
| NET r² | 0.197 | 0.181 |
| SERT r² | 0.352 | **0.017** |

Two rows of `pdsp_mat_profiles.csv` also carry a CXSMILES annotation block that RDKit's
default parser rejects; `external_final.py` strips it, which recovers maprotiline, a
genuine external compound that earlier builds dropped without a warning. The
pre-registered Stålberga panel and the Cui series are unaffected by the rule change —
the two filters remove the same four compounds from the first and none from either in
the second.

`modality_models.py`, `modality_external.py`, `modality_control.py` — whether separating
binding from functional uptake improves prediction.

- Internal, predicting modality-specific values: **+0.002 r² on average** (range −0.010 to
  +0.016 across six target × modality cells).
- External, matching-modality model versus pooled: **−0.067 r²**, better in 2 of 9 cells,
  Wilcoxon p = 0.250.
- Size-matched control: shrinking the *pooled* training set to the modality model's size
  costs −0.050 on its own, so only **−0.017 is attributable to modality** rather than to
  having less data.

The offset at NET is real and measurable; conditioning the model on modality does not
exploit it. This is consistent with the manuscript's existing result that applying the
measured offset as a constant correction worsened external fit.

`table1_consistent.md` — Table 1 with internal and external rows from the same
(pre-registered) model.

## 5. Exact reproduction of the two published external results

`repro/reproduce.py` regenerates both numbers that could not previously be rebuilt from
the deposit. Run it from the `repro/` directory. It reads `faithful_models.pkl`, `faithful_X.npy`,
`struct.csv` and `stalberga_parsed.csv` from the repository root, and `extended_set.csv`
and `struct_corrected.csv` from beside itself.

**The pre-registered test (n = 42).** A rebuild from the deposited `struct.csv` gives 43.
The cause is one structure: Cocaine is recorded as benzoylecgonine, its inactive
hydrolysis metabolite. The training set holds (−)-cocaine under the stereo-specific
InChIKey `ZPUCINDJVBIVPJ-LJISPDSOSA-N`, so the correct structure is caught by the overlap
filter and the wrong one is not. The single data error therefore produced both the wrong
molecule and the wrong compound count. With `struct_corrected.csv` the four exclusions are
2Me-α-PVP, 3Me-α-PVP, cocaine and MDMA, n = 42, and R² reproduces to four decimals:

| target | rebuilt | published |
|---|---|---|
| DAT | 0.459 | 0.459 |
| NET | 0.015 | 0.015 |
| SERT | 0.058 | 0.058 |

The overlap filter must be applied on the InChIKey **skeleton block**, not the full key:
ECFP4 ignores stereochemistry, so a stereoisomer of a training compound has a different
full key and an identical fingerprint.

**The extended set (R² = 0.183).** Two steps were unstated in Methods and both matter.
The DAT/SERT log-ratio is modelled **directly** — one regressor trained on the log-ratio
column — not differenced from the two per-target models, which gives 0.352 on the same
compounds. And the pooled statistic is computed on the **107** compounds from the three
Basel and Linköping sources; the seven Eshleman compounds are reported separately by
source, not pooled. With both, every published figure reproduces:

| | rebuilt | published |
|---|---|---|
| R² | 0.183 | 0.183 |
| r | +0.427 | +0.427 |
| RMSE | 1.335 | 1.335 |
| CCC | 0.305 | 0.304 |

Both clarifications are now in the manuscript's Methods.


## 6. Round-2 additions

`radioligand.py` — extracts the binding radioligand from `assay_description` and
stratifies the binding-versus-functional offset by it. `radioligand_followup.py` fits the
target x radioligand interaction, the within-compound contrast and the chemotype confound.
`radioligand_within.py` runs the within-document test. `fixed_effects_rl.py` refits the
2x2 inside each radioligand stratum and runs the wild cluster bootstrap-t.

**The headline result.** At NET the format effect is +0.507 (17 documents using
[125I]RTI-55) and +0.038 (21 using [3H]nisoxetine); the pooled +0.261 is an average of the
two. Within-document medians agree (+0.530 against -0.115, Mann-Whitney p = 5.5e-16). At
DAT and SERT the stratified offsets span -1.04 to +0.18. The offset is a property of the
assay cell, not of the assay format. Radioligand is collinear with document and nearly
with chemotype in this corpus, so the result establishes that the pooled estimate averages
over heterogeneous cells, not which feature of the cell is operative.

`censored_sensitivity.py` — refits the pipeline with a censored objective that penalises
predictions above the bound and leaves predictions below it free, over ten scaffold-CV
realisations, scoring on uncensored compounds only. Internal r2 changes by +0.007, +0.003
and -0.001.

`modality_gold_standard.csv` and `gs_annotation.txt` — 186 assay descriptions annotated
blind to the classifier's output under the rule stated in the manuscript's Methods, with
both labels, for re-scoring. The annotation was produced by a large language model under
that rule; it is a reproducible-rule annotation, not an independent expert gold standard.

`substrate_reference_set.csv` — the 55-compound releaser/blocker reference set with class
labels, against which `validate_substrate.py` scores the structural classifier.

### A note on sigma_e in the ceiling table

The two uptake-IC50 external sets are scored against a binding-dominated training median,
so the cross-assay dispersion applies and sigma_e is 0.445 / 0.655 / 0.492. The
PDSP/BindingDB set is all Ki and matches the training modality, so the cross-modality term
would be wrong there; those rows use the within-binding replicate dispersion instead,
0.452 / 0.457 / 0.463, pooled across replicate groups of the same compound at the same
target. The two agree at DAT and SERT and differ at NET, which is where the offset lives.

## Installing and running

Python 3.11 or later. From a clean environment:

```
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

`requirements.txt` pins the versions this deposit was last verified under. The analyses
do not depend on those exact versions, with two caveats worth knowing: LightGBM's RNG and
RDKit's InChI implementation are the two components whose behaviour could move a reported
figure if they changed.

Every script reads its inputs from the directory it is run in and writes its outputs
there. Run them from the repository root, except `repro/reproduce.py`, which runs from
`repro/`, and the scripts in `src/`, which need the flat directory `src/stage.sh`
builds -- see `src/README.md`.

```
python modality_classifier.py      # writes classified.csv; everything below needs it
python validate_substrate.py       # mechanism-classifier validation, ~10 s
python radioligand.py              # radioligand extraction and strata, ~1 min
python radioligand_within.py       # the within-document test, ~1 min
python fixed_effects_rl.py         # the stratified 2x2 and the wild bootstrap, ~6 min
python internal_full.py            # 20-seed scaffold CV, ~4 min, resumable per seed
python external_final.py           # article Tables 6 and 14
python censored_sensitivity.py     # the censoring sensitivity table, ~8 min
python modality_models.py && python modality_external.py && python modality_control.py
cd repro && python reproduce.py    # the two published external results, exactly
sh figgen/build_all.sh             # all 13 manuscript figures, in the one correct order
```

Expected total runtime is about 25 minutes on four cores. `internal_full.py` checkpoints
per seed, so an interrupted run resumes.

### Verifying the deposit

`repro/reproduce.py` is the fastest end-to-end check: it should print the
advance-specified external test at n = 42 with R2 = 0.459 / 0.015 / 0.058, and the
extended-set R2 = 0.183, r = +0.427, RMSE 1.335, CCC 0.305. If those four lines match,
the pipeline is intact.

`ruff check .` passes clean under the configuration in `ruff.toml`. That file documents
the three stylistic rules disabled everywhere, and the three waived for `src/` -- whose
scripts are kept byte-for-byte as they were run, because the Declarations' audit trail is
only worth something if the code behind it has not been tidied afterwards. A fourth
waiver, `F821 undefined-name`, is a correctness check rather than a stylistic one and is
waived for three files only: they inject their helpers by `exec`-ing a sibling's header,
which static analysis cannot follow. See `src/README.md`.
